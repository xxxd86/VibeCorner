# 猫角落 Corner · V2 产品定义（证据驱动）

> 输入：`docs/RESEARCH-CAT.md`（30 条行为学证据 + 23 条可编码规则）、`docs/RESEARCH-PSYCH.md`（28 条决策心理学证据 + 24 条设计动作 + 9 条拒绝清单）。
> 本文只做一件事：**说清旧定义错在哪、新定义是什么、哪条证据支撑哪个改动。**

---

## 1. 旧定义的问题

V1 的产品定义是：**「买前摆放检查：这个尺寸放不放得下」**。

研究之后，这个定义有两个硬伤：

1. **它检查错了对象。** 猫不用新猫窝/新抓板，第一因往往不是尺寸，而是位置（动线、遮蔽、邻接噪音、温度）。证据里最直接的一条：抓板放在猫经常活动的地方比放在偏僻角落更能减少乱抓（Demirbas 2024，n=1211，位置 p≤0.05，`S-02`）；而尺寸类的"阈值"大多是专家共识（`L-01`、`P-02`）。用户真正的痛点是"买了不用"，不是"买了放不下"。
2. **它给了一种假的确定性。** V1 用"60cm 通道"这类阈值做硬判定，但研究结论是：**这个数字查无实据**（`P-02`），"砂盆数量 = 猫数+1"的原文自称 historical rule of thumb（`R-02`），而且横断面数据里盆越多问题越多（OR 1.67—1.93，几乎必然因果倒置，`R-03`）。用这类阈值判"不合格"，会系统性误伤。

心理学一侧也有对应的问题：V1 的"只给 2—3 个方向"当时是用"选择过载"来解释的——但那是被过度引用的叙事（元分析平均效应量几乎为零，`CO-2`）。真实理由是**用户此刻偏好不确定 + 单步摩擦**（`CO-3`）。

## 2. 新定义

> **猫角落 = 买前的位置检查。**
> 拍下一个角落，先回答一个问题：**这个位置，猫会不会用？**
> 再回答第二个：**放不放得下？**
> 两个都通过，才给一份能带去店里的方案——每条结论都带依据，每个不确定都写明还要量什么，并且始终保留"什么都不买"的选项。

三句话的产品承诺：

1. **位置先于尺寸。** 位置不对，再合适的尺寸也白买。
2. **依据可核查。** 每条判断挂到具体文献或专家共识，并标强度——「研究支持（强/中）」「专家共识」「经验值」三种徽章，绝不混淆。
3. **不知道就说不知道。** 照片看不出来的（噪音源、体长、猫的性格），输出"这一步只能判断到 X，Y 要你现场确认"，而不是硬凑一个结论。

## 3. 证据 → 产品动作（只列真正改变产品的）

### 3.1 猫一侧

| 改动 | 证据 | 旧做法 → 新做法 |
|---|---|---|
| **新增「位置」评估：6 项 catFit** | AAFP/ISFM 环境需求五支柱（`H-02`/`R-01`/`S-01`/`V-01`/`T-01`）+ 实证项（`S-02`/`D-01`） | 原来只有尺寸条件 → 现在交付包第一个 tab 是「位置」：能藏 / 资源分隔 / 砂盆条件 / 抓挠位置 / 高处 / 温度日照，每项 pass/warn/fail/unknown + 一句机制解释 + 依据徽章 |
| **新增温度维度** | 猫等热区 30–38 ℃（`T-01`），20–22 ℃ 室温对猫偏冷 | 原来完全缺失 → L0 从照片读 `env`（地面材质 / 邻接家电 / 穿堂风 / 日照 / 是否外墙），温度项参与判断；照片看不出就 `unknown` |
| **砂盆位置邻接升级为可否决项** | `L-04`（不得邻洗衣机/冰箱/食盆/猫门；并排盆算一个大盆） | 原来只看尺寸 → 现在"砂盆挨着洗衣机"可直接 `fail` |
| **「60cm 通道」降级** | `P-02`：无任何研究支持该数字 | 原来可能判不合格 → 现在 `honest:true`，只给 warn/unknown，界面上标「经验阈值，不同猫有差异」 |
| **砂盆数量降为软建议** | `R-02` 原文自称经验法则；`R-03` 反向关联 | 原来按 n+1 判 → 现在只提示"可以再加一个，放另一处"，绝不 fail |
| **尺寸改成按体长算** | `L-01`（1.5× 体长，标注倍数是专家推荐） | 原来写死 cm → 现在按 `profile.catSize` 换算，并注明"体长是估算" |
| **时间维度进方案** | `N-02`（有遮蔽 2 天稳定 vs 无遮蔽 9 天，RCT）；`N-03`（砂盆移位原位 ≥2 周）；`N-01`（开箱先擦气味） | 原来只有一句 `aftercare` → 现在 `observe`（第 1/3/7 天看什么）+ `ifThen` + 「3 天不用不算失败」写进交付 |
| **抓板位置加权** | `S-02`（位置比尺寸更值得加权） | 抓板不再被默认推到墙角，而是判断"是否在猫的日常动线上" |
| **失败排查按可改顺序** | `F-01` + `L-05`（铲砂频率 OR 1.33—2.28，效应最大） | 排查清单顺序：脏 → 位置吵 → 盆小/有盖 → 猫间冲突 |

### 3.2 人一侧（只列有证据、成本低的）

| 改动 | 证据 | 具体做法 |
|---|---|---|
| **进度从 1/3 起步** | `PG-2` 起步赠进度：34% vs 19%（现场 n=720） | 照片一上传，进度显示「已完成 1/3」——因为"拍照片"真的是第一步 |
| **实施意图（if-then）** | `II-1` d=0.65（94 项检验）；`II-2` 计划句 +4.2pp（RCT） | 每条方案写成「如果进深 ≥60cm，就选 55×55，靠右墙放，前面留 40cm」；清单第一条是计划句「周六上午去店里，先看进深 ≥60cm 的方形窝」 |
| **小剂量劳动（量 1—2 个）** | `EF-1` IKEA 效应：**以"做成"为前提**（未完成会贬值 $1.46→$0.59） | 一卡一项、可跳过、可区间估；量完显示「这份方案用了你量的 3 个数」 |
| **可修改权** | `AA-2`：给一点点修改权就能挽回算法采纳 | 每个交付包都有「改一改」：改尺寸 / 拖热区 / 换方向，重算 |
| **尺寸条件排在商品之前** | `UC-1`（低专业度用户不给 AI 打折 → 必须靠结构纠偏）；`UC-2` | 交付包 tab 顺序：标注 → **位置 → 尺寸条件** → 建议 → 清单 |
| **三态未知与冲突同权重** | `UC-1`/`UC-2` | ⚠️未知 用和 ❌冲突 一样的视觉重量，并给下一步「量门洞宽度约 30 秒」 |
| **不用损失框架** | `FR-2`：预防类行为收益框架略优（r=0.083）；态度/意图无差异 | 文案一律收益框架：「这样放，猫更可能真的进去睡」，**禁止**「再不改猫会抑郁」 |
| **不用假置信度** | `UC-3`：LLM 自报置信度校准很差 | 禁止「87% 能放下」，改成「能放下（依据：进深 62cm ≥ 60cm）」 |
| **选择过载不做过硬结论** | `CO-2` 元分析≈0；`CO-3` 效应小且条件化 | 3 个方向上限定为**产品约束**（一屏扫完），不写成"心理学证明"；真正手段是"先问一个定方向的问题"（一次点击：猫不进去 / 太乱 / 有味道 / 都还行） |
| **不制造愧疚** | `PG-3`：蔡格尼克记忆优势**复现失败**；Ovsiankina 只支持"回到未完成任务" | 回访不说"你还没完成改造"，而是「上次停在量尺寸这步，继续只要 1 个数字」 |
| **等待要真实** | `PG-1` 目标梯度 + 诚实原则 | 3 步 checklist 对应真实 pipeline（读空间结构 / 估算尺寸关系 / 筛掉放不下的方向），不造假步骤 |

## 4. 反操纵承诺（写进产品，不只是文档）

以下 6 条是明确不做的，且每条都有研究/法规依据（详见 `RESEARCH-PSYCH.md` §3）：

1. 不做假社会证据（"92% 用户有效"）——假评论会伤到品类级信任（`He et al. 2022`）。
2. 不做倒计时 / 虚假稀缺——暗模式里最常见的一类（`DP-1`），且 EU DSA 第 25 条已立法禁止扭曲决策的界面（`DP-2`）。
3. 不做假精确置信度（`UC-3`）。
4. 不用损失框架恐吓（`FR-2`）。
5. 不做 confirmshaming（"算了，就让它睡地板"），不规定"不买"是失败。
6. 不预勾选任何附加项、不做 drip pricing（`DF-1` 默认效应是真实的，正因为它真，才不能用来对付用户）。

## 5. 现在的产品长什么样（一句话走完）

拍照 → （3 秒内）它说出照片里的具体位置并承认边界「看不出进深，这一步只能给方向」→
3 个方向（其中至少 1 个不用买东西），每张卡自带"先量什么" → 你点一下"最想解决什么"再看推荐 →
量 1—2 个数字（一卡一项，可区间估，进度从 1/3 起步）→
交付包：**位置**（6 项 + 猫会怎么用 + 怎么观察）→ **尺寸条件**（三态 + 依据徽章）→ **建议**（新品/复用同权）→ **清单**（if-then + 计划句）→
带得走的标注图 + 第 2/7 天两条轻回访。

## 6. 尚未解决的诚实边界

- 猫窝使用率**没有**原因排序研究（`F-03`），所以产品给"逐项排查"，不给"最可能的原因排名"。
- 朝向、颜色、方位、绝对高度这些流传说法**无证据**，产品一律不评。
- 情绪/性格维度照片看不出来，只能靠用户自述与观察清单补。
- 本产品**不能**替代现场确认：照片无法判断承重、墙体、电线、猫的实际反应。
