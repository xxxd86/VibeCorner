# 手机端真机验收清单（iPhone / Android）

> 我在大屏浏览器 + CDP 真设备仿真里能覆盖尺寸、DPR、触控、布局；
> **键盘弹起、相册选图、PWA 安装、系统通知**这几件事只有真机能定论。
> 这份清单是给"你拿着手机"用的：你照着点一遍，把打勾结果和自检报告发我，我按报告修。

---

## 0. 前置（1 分钟）

1. 手机连**同一个 Wi-Fi**
2. 打开 **http://192.168.1.5:8848**
3. 顺手打开自检页：**http://192.168.1.5:8848/mobile-check.html**
   → 点「复制报告」把文字发我（含 UA、视口、安全区、键盘、选图、通知能力检测，**不含任何照片**）

自检报告里我会重点看：

| 字段 | 期望 |
|---|---|
| `io.ios` | iPhone 上为 `true` |
| `vp.safe.top/bottom` | 刘海屏应有非 0（如 47 / 34） |
| `vp.dvh` ≈ `vp.ih` | 说明 `100dvh` 可用；差很多说明系统旧 |
| `kbd.hiddenPx` | 键盘弹起时 200–350px 属正常 |
| `kbd.covered` | **必须为 false**（输入框被键盘盖住就是 bug） |
| `photo.type / w / h` | 能选到图、能解码 |
| `photo.compressedKb` | < 900（客户端压缩生效） |
| `notify.hasNotification` | iOS Safari 标签页里可能是 false（正常） |
| `io.standalone` | 加到主屏后从主屏打开应为 `true` |

## 1. 首屏（30 秒）

- [ ] 打开后 2 秒内看到欢迎态，没有白屏/闪烁
- [ ] 标题、按钮在安全区内（不被刘海/圆角裁切）
- [ ] 上下滚动顺滑，没有横向滚动条
- [ ] 底部输入区没有被浏览器工具栏盖住

## 2. 拍一张 / 选一张（1 分钟）

- [ ] 点相机按钮 → 弹出「拍照 / 照片图库 / 浏览」
- [ ] 选一张相册里的照片，能上传并开始分析
- [ ] 上传后照片不歪（EXIF 方向正确）
- [ ] 分析等待时有进度提示，不是空白

## 3. 键盘（30 秒）

- [ ] 点输入框，键盘弹起后**输入框仍可见**（没被盖住）
- [ ] 能输入中文（拼音候选条正常）
- [ ] 收起键盘后布局恢复，不残留空白

## 4. 标注查看（30 秒）

- [ ] feed 顶部照片条 → 点开全屏标注
- [ ] 编号热区和图例能对上
- [ ] 工具条（缩小/适应/放大/点选）按钮好点，不误触
- [ ] 关闭按钮（左上 ×）好点，关闭后回到原来的位置

## 5. 家人这一侧（1 分钟）

- [ ] 分享出去，用**另一台手机或微信里打开**链接
- [ ] 家人页首屏能看到结论和位置判断
- [ ] 「我能做什么」4 个按钮好点（44px），选中态明显
- [ ] 选「我拍了现场照」→ 勾选同意后「发送」才可点
- [ ] 发送后出现「已告诉 TA」

## 6. 加到主屏（1 分钟）

- [ ] Safari 分享 → 添加到主屏幕 → 从主屏图标打开
- [ ] 打开后是**全屏**（没有 Safari 地址栏），`io.standalone=true`
- [ ] 主屏图标不是白图/糊图（maskable 图标正常）

## 7. 通知（可选，iOS 需 16.4+ 且已加到主屏）

- [ ] 交付卡出现「家人回应时提醒我」按钮
- [ ] 点它 → 系统询问通知权限
- [ ] 让家人发一条回应 → 应用切到后台时能收到系统通知
- [ ] 点通知 → 回到应用并停在「家人回应」那张卡

> 如果第 7 项在 iOS Safari **标签页**里失败：这是系统限制（只有"添加到主屏"的 PWA 才支持），不是产品 bug。
> 报告里 `notify.hasNotification=false` 或 `permission=denied` 我会如实记录，按钮会自动变成「浏览器不支持提醒」。

## 8. 边角（各 10 秒）

- [ ] 横屏打开一次，布局不崩
- [ ] 系统深色模式打开一次（当前是固定浅色主题，应保持可读）
- [ ] 切到别的 App 再切回来，会话还在
- [ ] 关掉 Wi-Fi 用 4G 打开局域网地址 → 应提示"需要在同一个 Wi-Fi"

## 怎么把结果给我

1. 自检页「复制报告」的全文
2. 拍 2–3 张截图（首屏 / 键盘弹起 / 家人页）
3. 哪一条打不了勾，用一句话描述（例如「键盘弹起后输入框被盖住一半」）

我按这个改，不需要你再描述环境——报告里已经有 UA、视口、安全区、DPR。

## 我知道的、暂时不承诺的

| 项 | 现状 |
|---|---|
| iOS 推送通知 | 只有「加到主屏 + 16.4+」才可能；本轮只用 `new Notification()`，失败静默 |
| 微信内置浏览器 | 分享链接在微信里打开可能被拦（非白名单域名）；建议用系统浏览器 |
| 离线使用 | 没有 Service Worker 缓存，断网打不开 |
| 后台保活 | 没有后台同步，切走后不会自动刷新（回来时会拉一次） |
